SocioNet

Kotlin, Jetpack Compose, Firebase, Room DB, Hilt

View source on GitHub Request a demo

App Screenshots

Problem

Residential communities often need one place to coordinate visitor access, staff information, and resident complaints. SocioNet brings these day-to-day management tasks into a role-based Android app.

What I Did

  • Built a native Android application using Jetpack Compose and MVVM Clean Architecture featuring role-based dashboards, visitor tracking, staff registries, and complaint management modules.
  • Integrated Room Database DAOs with Cloud Firestore to provide offline data caching and injected dependencies across layers using Dagger Hilt.
  • Implemented a Gatekeeper QR code scanner workflow for fast visitor verification at residential society gates.
  • Separated Resident, Admin, and Security Guard interfaces with role-based access control using Firebase Authentication, including resident home and administrator dashboard workflows.

Result

Residents, administrators, and gate security use role-specific workflows, including QR-based visitor checks at the entrance. Room DAOs keep core society information available offline while Firestore provides the connected data layer.
