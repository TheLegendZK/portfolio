Tech Articles

Flutter, Dart, Riverpod, DEV.to REST API

View source on GitHub Request a demo

App Screenshots

Problem

Finding relevant developer articles and returning to saved reads can be cumbersome across devices and network conditions. Tech Articles brings a tag-filtered DEV.to feed and saved articles into one responsive client.

What I Did

  • Developed a cross-platform developer news client consuming the DEV.to REST API with tag-based filtering, infinite-scroll pagination (ScrollController), and derived Riverpod providers for real-time search filtering.
  • Designed an offline-first caching layer using SharedPreferences and JSON serialization to persist bookmarked articles and cache the home feed for seamless offline reading with automatic retry banners.
  • Built an Adaptive Layout (LayoutBuilder + MediaQuery.textScalerOf) that dynamically transitions between a single-column mobile ListView and a multi-column tablet/desktop GridView without render overflows.
  • Wrote automated Unit and Widget Tests (flutter_test) validating null-safe JSON deserialization and reactive bookmark state toggling.

Result

Combining LayoutBuilder with MediaQuery.textScalerOf eliminated render overflows across phone, tablet, and desktop viewports, from 960×600 to 960×2133. Local JSON caching keeps bookmarked reads accessible completely offline.
